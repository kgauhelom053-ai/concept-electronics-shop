# Concept: Electronics & Appliances Shop Landing Page

Live: https://kgauhelom053-ai.github.io/concept-electronics-shop/

A mobile-first, single-file landing page concept for an electronics and home appliances shop. **The shop name, prices, address and contact details are all placeholders.** This is not a real store's website.

Easy to rebrand: replace "Your Shop Name", point `#whatsapp` / `#call` links to `https://wa.me/<number>` and `tel:+<number>`, and change `--brand` / `--accent` colours.
